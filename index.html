Циклы for в Python

✨ Интерактивная доска: изучаем итерации, range() и логику управления циклами

📌 1. Как устроен цикл for?

В Python цикл for используется для итерации (перебора) элементов любой последовательности (списка, строки, диапазона чисел).

for элемент in последовательность:
    # Код, выполняемый для каждого элемента
    print(элемент)

Переменная цикла автоматически принимает значение каждого элемента по очереди. Индексы вручную отслеживать не нужно!

💡 Важно: Количество повторений цикла всегда равно количеству элементов в последовательности, если не прервать его досрочно.

🧠 4. Управление циклом: Условия

Внутри цикла можно использовать операторы ветвления:

  • break — мгновенно прерывает и завершает весь цикл.
  • continue — пропускает остаток кода и переходит к следующему шагу.
for num in range(1, 6):
    if num == 3:
        # Выберите оператор кнопкой ниже

⚡ 5. Интерактивное ветвление внутри цикла (Краш-тест условий)

Давай прогоним цикл от 1 до 10 и внутри каждого шага проверим условие: если число делится на 3 без остатка, выведем специальную метку!

for x in range(1, 11):
    if x % 3 == 0:
        print(f"{x} делится на 3!")
Нажмите кнопку запуска, чтобы увидеть, как интерпретатор Python проверяет условия на лету!

📖 Опорный конспект: Продвинутые циклы в Python
📌 Цикл for — идеальный инструмент, когда количество повторений известно заранее.
🔹 Итерируемый объект: любой объект, способный отдавать элементы по одному (списки [], строки "", кортежи, словари).
🔹 range() нюанс: правая граница (аргумент stop) никогда не включается в диапазон. Вызов range(1, 4) вернет 1, 2, 3.
🔹 Функция enumerate(): Если в цикле одновременно нужны и индекс, и значение, используй for idx, val in enumerate(my_list):.
🔹 Конструкция for ... else: Блок else выполнится по окончании цикла, но только если цикл не был прерван оператором break!
