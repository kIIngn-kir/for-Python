🔄 Цикл for в Python:
интерактивные примеры + лайфхаки

Цикл for — это как конвейер: он берёт каждый предмет из коллекции и делает с ним одно и то же действие.
🔍 Нажми на лупу (🔍) у любого кода — получишь полезный факт или лайфхак!

📦 1. Как работает for? Список

🤖 Нажми "Запустить" → увидишь конвейер в действии.
for animal in ["🐱", "🐶", "🐭"]:
    print(animal)

🔢 2. range() — повторяем N раз

Повторить: N = 5
🤖 Настрой ползунок и нажми Старт.
for i in range(5):
    print("Привет", i)

⏸️ 3. Управление: continue и break

🤖 Выбери режим симуляции выше.
for num in range(1, 6):
    if num == 3:
        continue   # или break
    print(num)

🔍 4. if внутри for: фильтр

🤖 Нажми на кнопку для запуска фильтрации массива.
numbers = [3, 8, 11, 14, 5, 20]
for n in numbers:
    if n % 2 == 0:
        print(n, "чётное!")

🧮 5. Накопление суммы

🤖 Нажми для пошагового суммирования элементов.
numbers = [4, 7, 2, 9, 5]
total = 0
for val in numbers:
    total += val
print("Сумма =", total)

📝 6. Цикл по строке

🤖 Введи слово и запусти посимвольный перебор.
word = "Python"
for letter in word:
    print(letter)

🎯 7. Поиск элемента (for..else)

🤖 Нажми для проверки работы блока else в цикле.
data = [10, 23, 42, 55, 7]
for num in data:
    if num == 42:
        print("Нашли!")
        break
else:
    print("Не нашли")

🗂️ 8. Вложенные циклы for

🤖 Матрица перемножения сгенерируется здесь.
for i in range(1,4):
    for j in range(1,4):
        print(i*j, end=" ")
    print()

✨ 9. Генератор списков

🤖 Результат однострочного синтаксиса Python.
# Классический цикл
squares = []
for x in range(1, 6):
    squares.append(x**2)

# Генератор списка
squares = [x**2 for x in range(1, 6)]

🧠 Главная идея цикла for: «для каждого элемента из коллекции сделай действие».
🔹 Список, строка, range, словарь — всё можно перебирать.
🔹 break — выход, continue — пропуск шага.
🔹 for..else — редкая, но мощная конструкция для поиска.
📌 Нажимай 🔍 у каждого примера — там много полезных лайфхаков!
